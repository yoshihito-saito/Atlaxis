# Atlaxis v0.2.1 release

## Goal and scope

Commit and publish the current planning, probe-library and channel-editing
changes as v0.2.1. Build Windows x64 and macOS arm64 installers with the existing
desktop workflow and publish both installers with matching source. Preserve
existing releases, user data and manual export snapshots.

## Steps

1. Review the pending release diff and existing validation records; synchronize
   the package/runtime/lock version to 0.2.1 without changing dependencies.
2. Commit the requested changes on main, push and tag the exact build commit.
3. Run the existing desktop workflow for that tag and collect its final results.
4. Verify artifact/source identity, publish the three release assets and record
   the release URL, build results and remaining validation boundaries.

## Validation boundaries

Prior focused checks covered the two Mini-Amp maps and the NP2013 Geometry
double-click/availability behavior. The final Order column was source-inspected.
Full application checks were blocked by this sandbox's OpenGL initialization;
no claim of full GUI, real recording, hardware or downstream sorting validation.
The requested release builds do not establish those behaviors.

## Preparation

The release includes the Mini-Amp-128 H20/E-1 profiles, channel-map Order column,
Site ID labels and Geometry double-click editing, independent probe visibility,
depth-aware rendering and edit history, folder-based plan saving, and processing
exports beside the `atlaxis/` support folder. Package/runtime/lock versions are
0.2.1; dependency versions and the existing desktop workflow are unchanged.

## Publication outcome

Implementation commit `beda46364e2df833cf0b40ad7f996bf23a794911` was pushed to
main and tagged `v0.2.1`. The staged diff was reviewed and `git diff --cached
--check` passed after removing one extra trailing blank line from the channel
selection record. No additional local tests were run for publication.

[Desktop workflow 38634702941](https://github.com/yoshihito-saito/Atlaxis/actions/runs/38634702941)
succeeded for Windows 2022 x64 and macOS 14 arm64, including native PyInstaller
builds and installer packaging. Both downloaded Actions archives matched their
API sizes/SHA-256 digests. Their source ZIPs identify the tagged commit and
package/runtime/lock version 0.2.1. The macOS source ZIP supplies release source.

[Atlaxis v0.2.1](https://github.com/yoshihito-saito/Atlaxis/releases/tag/v0.2.1)
was published as Latest with `Atlaxis-macOS-arm64.dmg`,
`Atlaxis-Windows-x64-Setup.exe` and `Atlaxis-source.zip`. All three uploaded
sizes/SHA-256 digests matched the prepared files, and the latest-release API
confirmed the published release. Existing releases were retained.

The new installers were not launched or installed locally. Full GUI, real-data,
hardware and downstream sorting behavior remain unverified. Existing licensing
and source-distribution caveats remain linked in the release notes; build
success is not a claim that those outstanding checks were resolved.
