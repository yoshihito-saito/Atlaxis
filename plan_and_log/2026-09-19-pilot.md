# Probe insertion planner pilot

## Goal and scope

Implement the supplied specification's Phase 1 vertical slice in an empty repository: Python 3.11/uv desktop application, BrainGlobe Waxholm atlas, arbitrary probe geometry and NeuroSuite channel mapping, interactive 3D pose, per-contact anatomical assignment, and portable project save/load. Follow the repository's single-agent workflow. Preserve the pre-existing untracked AGENTS.md.

## Implementation steps

1. Establish packaging, locked dependencies, platform CI, and documented coordinate conventions.
2. Implement Qt-independent geometry/mapping validation, CellExplorer MAT and NeuroSuite XML import, explicit atlas/stereotaxic transforms, BrainGlobe loading, and vectorized region lookup.
3. Implement dark Qt/PyVista application with atlas loading, generic probe imports, numerical pose controls, cached geometry, and sortable contact table.
4. Implement self-contained versioned project persistence and document operation, calibration, and pilot limitations.
5. Review the scoped diff and run one lightweight changed-file check; record results and remaining work.

## Constraints and acceptance

- Keep physical contact IDs, device channels, local coordinates, atlas coordinates, and stereotaxic coordinates distinct. Internal distances are micrometers; UI stereotaxic distances are millimeters.
- BrainGlobe orientation/resolution and annotation are the anatomical source of truth. Bregma must use a supplied calibration or verified atlas landmark and be saved; never infer it from an origin or arbitrary landmark.
- Define rotation/depth conventions explicitly and use a rigid homogeneous transform. Zero depth places the tip at the specified entry/reference coordinate; depth moves it along the insertion axis. Probe geometry must document its origin and axes.
- Validate IDs, mappings, finite values, dimensions, rotations, and volume bounds; points outside the annotation must not wrap or clip to a brain region.
- Preserve probe-local CellExplorer geometry and XML group order/skipped channels. Reject unsupported or ambiguous input clearly rather than guessing channel associations.
- Atlas loading must not block the UI; move cached probe actors with transforms. Save sufficient calibration, geometry, channel-map, and pose data to reopen without source files.
- No Neuropixels routing, NeuroCarto, fabricated anatomy, fixed vendor catalogue, installers, slice browser, or other later-phase features.
- No added tests or broad verification under repository rules. Runtime and cross-platform limitations must be reported honestly.
